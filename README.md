# Ghavish Subratty - Personal ePortfolio

Welcome to the repository for my personal ePortfolio! This website is a digital showcase of my work, technical skills, and academic journey as a BSc Computer Science student at the University of Mauritius, with an expected graduation in July 2028.

This application was built to provide a centralized hub for my software development projects, technical certifications, and professional background.

## Featured Projects

### 1. MoLakaz (AI Household Chore Planner)
*   **Overview:** A mobile app that splits household chores fairly around each family member's free time, built at the Meta Global AI Hackathon, where I was Team Lead.
*   **Key Features:** Before-and-after photo checks with SAM 3.1 on cloud GPUs, Whisper voice input, and an AI assistant that rearranges the week without breaking fairness rules.
*   **Tech Stack:** Expo (React Native), Python, FastAPI, Modal, SAM 3.1, Whisper.

### 2. MoBudget (Trilingual Money Planner)
*   **Overview:** A budgeting web app for young Mauritians, built at the Finnovate hackathon, where I was Team Lead of team Cache Me Outside.
*   **Live app:** https://cache-me-outside-topaz.vercel.app/
*   **Key Features:** English, French and Kreol Morisien; AI reading of payslips, receipts, camera scans and voice notes; Safe / Tight / Not yet verdicts for savings goals; an AI coach.
*   **Tech Stack:** React, Vite, Tailwind CSS, Firebase Auth, n8n, MongoDB, Gemini.

### 3. TrustyHands (Home Services Marketplace)
*   **Overview:** A platform connecting homeowners with vetted tradespeople. I was Project Lead and architect for team Git Happens.
*   **Key Features:** Client, service provider and admin workspaces; booking and scheduling; provider verification; subscription tiers; analytics dashboard; English and French.
*   **Tech Stack:** Django, Python, MongoDB Atlas, Chart.js, Figma.

### 4. SmartRupi (Fintech Mobile App)
*   **Overview:** Built during the 12-Hour UoM AutoForge Hackathon, where I was Team Lead of a 5-person team.
*   **Key Features:** A multi-agent AI system for scam analysis, spending audits, investment suggestions and loan matching.
*   **Tech Stack:** React Native, Expo, Node.js, Python, BAND AI, Gemini, Microsoft SQL Server.

### 5. TREAD (Telemetry, Rental and Emergency Alerts Database)
*   **Overview:** A dashboard for telemetry tracking, rental management and emergency alerts.
*   **Key Features:** I designed the database architecture and built the dashboard.
*   **Tech Stack:** Python, Streamlit, Pandas, Folium, Microsoft SQL Server.

### 6. Monte Carlo Supermarket Simulator
*   **Overview:** A two-cashier queueing simulation measuring wait times, queue lengths and cashier utilisation.
*   **Tech Stack:** Python, Pandas, Matplotlib, Streamlit.

### 7. MARIE Matrix Solver and Numerical Linear Algebra Solver
*   **Overview:** Assembly subroutines for 3x3 matrix algebra in MARIE, and an Excel engine for determinants, inverses, LU decomposition and Gauss-Seidel/Jacobi iteration.
